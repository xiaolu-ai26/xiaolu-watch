# 原生 Flow 阅读页

今日页采用暖白底、大日期与钴蓝半调扭流，正文直接排版，不使用重复卡片堆叠。日期来自实际所选日期；日概览、全文入口、身体背景与后续记录均可随内容增长。身体背景默认收起，显示实际测量截止；未知时间不会用页面生成时间替代。主线与全部记录共用原始卡 ID，不按声音归属或字数删除短想法，回收仍使用原有精确预览与确认协议。

## 渲染方式

`EditorialFlowDensity.png` 是不含文字、人物或私人内容的专用生成流形资产，只承载半调密度和配色。Metal 将它作为局部流场参考：底场保留选定的局部悬浮与呼吸，固定包络保持 S 形透明通道；50,008 个独立圆点根据密度资产逐行求出的弯曲河道轴保持各自泳道，从底部沿 S 形轨迹向上前进，在可见范围外衔接下一轮。没有将整张 App 截图当成界面，也不是整张纹理统一平移。

Metal 源码和管线在视图生命周期内初始化一次。绘制循环复用纹理和管线，不逐帧编译，不逐帧构建数万个 SwiftUI View 或 CPU 路径。前台请求 60 FPS；这是目标，不是对所有 iPhone 的性能保证。减少动态效果、离开可见区域、App 非活跃或系统严重过热时保持静态完整构图并停止循环；低电量开关本身不会自动降低默认视觉品质。GPU 不可用时显示同一纯流静态资产。

## 数据与阅读

- 概览的处理范围与部分完成状态来自可选接口字段，旧接口仍可读取。
- 品牌下方显示最新录音事件截止与等待整理的段数。可选 `ingestion` 分别提供已接收、已转写、连续已整理的事件截止及排队状态；不使用概览覆盖或接口生成时间冒充最新录音时间。字段缺失时显示“录音状态待同步”，预算等待也不等于没有录音。
- 身体测量截止独立于页面更新时间；采集与推断结果仍遵守健康与位置背景的既有规则。
- 归属说明在详情中按需阅读，不变成摘要套话或内容过滤器。
- 详情保留摘要、口语清稿、七删一改整理稿。增大字体时正文可重新排版，不能用固定高度裁掉完整稿。
- 主线、全部记录与首条推荐均按录音结束时间由新到旧排列，不使用模型更新时间；小时定位仍指向所选时刻后最近的录音事件。
- 定时结果读取由 Coordinator 单独负责，页面只在日期、连接或前台状态改变时请求刷新。

## 验证边界

本轮有同一合成内容的 SwiftUI 布局与真实 Metal 管线帧预览，可与选定视觉目标比对。Mac 离屏 GPU 耗时和 Mac 显示循环只说明开发机表现，不代表 iPhone 实际帧率、功耗、温升或长时录音体验。真机截图、前台流动与数据联调须在 Phone 覆盖安装后分别核验；不需要更改 Watch 录音、卸载应用或重新配对。
